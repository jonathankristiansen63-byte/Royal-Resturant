Royal Angkor Khmer Kitchen nettside

Åpne index.html i nettleseren for å se siden.

Innhold:
- index.html: selve nettsiden
- styles.css: design og responsiv layout
- script.js: menyfilter og sticky header
- assets/: lokale matbilder hentet fra offentlige Foodora-/Restaurant Guru-kilder

Kilder brukt:
- Foodora: offentlig restaurantprofil, meny, telefon, adresse og produktbilder
- Restaurant Guru: offentlig mat-/menybilde
- Brukerens Google-utdrag: rating, anmeldelser og synlige kundesitater
